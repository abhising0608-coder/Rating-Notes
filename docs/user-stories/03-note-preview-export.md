# User Stories: Note Preview & Export

This document outlines the user stories for the final preview and export functionalities of the Rating Note.

---

### Previewing the Rating Note

- **UP-1.1**: As a Rating Analyst, I want to access a "Preview" mode that shows me a clean, read-only version of the entire Rating Note as it will appear in the final report.

- **UP-1.2**: As a user (Analyst, QC, RCM), I want the preview page to only display sections that were marked as "Applicable" so I can review the final, concise document.

- **UP-1.3**: As a user, I want the preview to include an auto-generated table of contents with clickable links that jump to the corresponding sections.

- **UP-1.4**: As a user, I want the preview to correctly render all tables, formatted comments, and attached images in their respective sections.

- **UP-1.5**: As a user, I want to see a consistent header (with company name and other details) and footer (with page numbers and version) on the preview page.

---

### Exporting the Rating Note

- **UP-2.1**: As a Rating Analyst, I want to be able to export the complete Rating Note to a Microsoft Word (.docx) file so that I can perform final edits or share it in a standard format.

- **UP-2.2**: As a Rating Analyst, I want the exported Word document to retain all formatting, tables, and images from the preview page, including headers and footers.

- **UP-2.3**: As a Rating Analyst, I want to be able to export the complete Rating Note to a PDF file for secure, read-only distribution.

- **UP-2.4**: As a Rating Analyst, I want the exported PDF to be a high-fidelity copy of the preview page, with proper page breaks, headers, footers, and hyperlinks.

- **UP-2.5**: As a Rating Analyst, I want the option to export the note as a standalone HTML file for web-based viewing or archival.
